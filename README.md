Warung Kilat — a fast-paced Indonesian kitchen game. Take orders from the board, chop, cook, plate and serve dishes before the timers run out. Three recipes combine the same fresh ingredients in different ways, the rush grows every level, and every second counts. Runs offline in any desktop browser, no build step, no network.

## Run it

```sh
node serve.ts
```
